# Code of Conduct

DeenNotes contributors should keep technical discussion respectful, specific, and focused on the work.

## Expected behavior

- discuss code and product decisions without personal attacks
- assume good faith while still reviewing critically
- protect user privacy and never post sensitive account or journal data
- respect the product's faith-sensitive context
- distinguish personal religious opinions from product requirements

## Unacceptable behavior

Harassment, threats, discriminatory attacks, deliberate disclosure of private information, credential sharing, or attempts to use the project to present AI output as authoritative religious rulings are not acceptable.

Repository maintainers may remove content or participation that violates these expectations.
